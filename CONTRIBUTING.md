# Как дополнять LinuxHelp

Спасибо, что помогаете улучшать шпаргалки.

## Стиль

- Язык: **русский** (техтермины и команды — как в shell).
- Каждый новый `.md`: строка **← [README](README.md)** и 2–4 перекрёстные ссылки на связанные файлы.
- Bash-блоки: поясняющие комментарии **`#`** в конце строки где уместно.
- Один файл — одна тема; длинные cookbooks (как `routine_automation_scripts.md`) — с оглавлением по §.
- Debian/Ubuntu по умолчанию; отличия RHEL — короткой ремаркой.

## Добавление шпаргалки

1. Создайте `topic_cheatsheet.md` в корне репозитория.
2. Добавьте пункт в **Структура репозитория** и строку в таблицу **Дополнительные шпаргалки** в [README.md](README.md).
3. При необходимости — 1–3 ссылки **из** существующих файлов (incidents, logs, README index).
4. Коммит: краткое сообщение на английском в стиле истории git (`Add … cheatsheet for …`).

## Чего избегать

- Секреты, `.env`, ключи, реальные IP/домены production (используйте `example.com`, `203.0.113.x`).
- Дублирование целых разделов README без необходимости — лучше ссылка на дочерний MD.

## Вопросы

Issues и PR — по процессу вашего хостинга репозитория (GitHub / Cursor origin).
