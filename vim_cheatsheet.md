# Vim: шпаргалка для сервера и конфигов

← [README](README.md) · основы shell: [linux_install_and_basics.md](linux_install_and_basics.md)

Vim есть почти на каждом Linux (в т.ч. minimal/server). Удобен для правки `/etc/nginx/nginx.conf`, unit‑файлов, скриптов по SSH.

**Режимы:** Normal (навигация/команды) → Insert (ввод текста) → `:` (командная строка). `Esc` возвращает в Normal.

---

## 1. Запуск и выход

```bash
vim file.txt                 # открыть (или создать) файл
vim +10 file.txt             # открыть, курсор на строке 10
vim -o a.txt b.txt           # два файла в горизонтальных окнах
vim -O a.txt b.txt           # два файла в вертикальных окнах
vimtutor                     # интерактивный урок (~30 мин, en/ru если установлен locale)
sudoedit /etc/nginx/nginx.conf   # правка системного файла через временную копию + sudo
view file.txt                # только чтение (или vim -R)
```

| Действие | Команда в Normal / `:` |
|----------|-------------------------|
| Выйти без сохранения | `:q!` |
| Сохранить | `:w` |
| Сохранить и выйти | `:wq` или `ZZ` |
| Сохранить как | `:w newname.conf` |
| Выйти (файл не менялся) | `:q` |
| Принудительно перезаписать | `:w!` (осторожно на production) |

## 2. Insert: как начать печатать

| Клавиша | Комментарий |
|---------|-------------|
| `i` | Insert перед курсором |
| `a` | Insert после курсора |
| `I` | Insert в начале строки |
| `A` | Insert в конце строки |
| `o` | Новая строка ниже и insert |
| `O` | Новая строка выше и insert |
| `Esc` | Вернуться в Normal |

## 3. Движение (Normal)

| Клавиша | Комментарий |
|---------|-------------|
| `h` `j` `k` `l` | Влево / вниз / вверх / вправо |
| `w` / `b` | Следующее / предыдущее слово |
| `0` / `$` | Начало строки / конец строки |
| `gg` / `G` | Первая / последняя строка файла |
| `10G` или `:10` | Перейти на строку 10 |
| `%` | Парная скобка `()[]{}` |
| `Ctrl+f` / `Ctrl+b` | Страница вниз / вверх |
| `H` / `M` / `L` | Верх / середина / низ экрана |

## 4. Просмотр длинных файлов и логов

| Клавиша / команда | Комментарий |
|-------------------|-------------|
| `:set nu` | Показать номера строк |
| `:set nonu` | Скрыть номера |
| `:set relativenumber` | Относительные номера (удобно `10j`) |
| `Ctrl+d` / `Ctrl+u` | Полэкрана вниз / вверх |
| `/pattern` | Поиск вперёд |
| `?pattern` | Поиск назад |
| `n` / `N` | Следующее / предыдущее совпадение |
| `*` / `#` | Поиск слова под курсором вперёд / назад |
| `:noh` | Убрать подсветку поиска |
| `v` + выделение + `:w >> log.txt` | (редко) — проще `:r` или внешний `grep` |

Открыть файл с конца (свежие строки лога):

```bash
vim + file.log             # + без номера — последняя строка (не всегда; надёжнее:
tail -n 200 file.log | vim -   # последние 200 строк через stdin (- — буфер без имени)
```

В vim: `:e file.log` — открыть другой файл; `:e#` — вернуться к предыдущему буферу.

## 5. Редактирование текста

| Команда | Комментарий |
|---------|-------------|
| `x` | Удалить символ под курсором |
| `dd` | Вырезать (удалить) строку |
| `3dd` | Три строки |
| `yy` | Копировать строку |
| `p` / `P` | Вставить после / перед курсором |
| `u` | Отменить |
| `Ctrl+r` | Повторить (redo) |
| `>>` / `<<` | Сдвинуть строку вправо / влево (отступ) |
| `J` | Склеить текущую строку со следующей |
| `ci"` / `ci(` / `ci{` | Change inside quotes/brackets — заменить содержимое |
| `di"` | Delete inside — удалить содержимое в кавычках |
| `r` | Заменить один символ |
| `R` | Replace mode (замена посимвольно) |
| `.` | Повторить последнее изменение |

Visual mode: `v` — посимвольно, `V` — строки, `Ctrl+v` — блок. Затем `d` / `y` / `>`.

## 6. Поиск и замена

В Normal:

```
/pattern                   # искать pattern
/\cpattern                 # без учёта регистра
```

Ex-замена (командная строка `:`):

```
:%s/old/new/g              # все вхождения в файле
:%s/old/new/gc             # с подтверждением каждого
:10,20s/old/new/g          # только строки 10–20
:s/old/new/g               # текущая строка
```

| Флаг | Комментарий |
|------|-------------|
| `g` | Все вхождения в строке/диапазоне |
| `c` | Confirm — спросить |
| `i` | Ignore case (или `:set ic`) |

Экранирование `/` в пути: используйте другой разделитель, например `:%s#/old/path#/new/path#g`.

| Команда | Комментарий |

## 8. Полезно при правке конфигов

```bash
# проверка синтаксиса после правки — вне vim, в shell
sudo nginx -t                # nginx
sudo sshd -t                 # sshd
systemd-analyze verify /etc/systemd/system/my.service
```

В vim перед сохранением:

```
:set paste                   # вставка из буфера без лишних отступов (потом :set nopaste)
:set expandtab tabstop=2 shiftwidth=2   # пробелы, ширина таба (пример для yaml)
:set syntax=nginx            # подсветка, если установлен vim-runtime с syntax
:set fileencoding=utf-8      # явная кодировка
:w !sudo tee %               # сохранить файл, открытый без sudo (осторожно)
```

`:w !sudo tee %` — запасной вариант, если забыли `sudoedit`; предпочтительнее **sudoedit** или `vim -c 'set nobackup' -c '%!sudo tee %'`.

## 9. Минимальный `~/.vimrc`

```vim
" ~/.vimrc — комментарии в vim начинаются с "

set number                   " номера строк
set relativenumber           " относительные номера (опционально)
set tabstop=4 shiftwidth=4 expandtab   " 4 пробела вместо табов
set autoindent               " перенос отступа с предыдущей строки
syntax on                    " подсветка синтаксиса
filetype plugin indent on    " отступы по типу файла

set hlsearch                 " подсветка совпадений поиска
set incsearch                " поиск по мере набора
set ignorecase smartcase     " без регистра, но с регистром если есть заглавные

set backupcopy=yes           " лучше для редактирования через sudo/symlink
set noswapfile               " на VPS можно отключить swap vim (опционально)

colorscheme desert           " схема (desert, slate, default)
```

Применить без перезапуска: `:source ~/.vimrc` или `:so ~/.vimrc`.

## 10. Если «застряли»

| Ситуация | Решение |
|----------|---------|
| Набираете текст, буквы не появляются как ожидалось | Нажмите `Esc`, проверьте `-- INSERT --` внизу |
| «Звонит» terminal (bell) | Вы в Normal и жмёте `j` на пустой строке — нормально; или `:set vb` |
| Файл «readonly» | `:w !sudo tee %` или закрыть и `sudoedit файл` |
| Случайно `q` в Normal | `:q!` если не сохраняли нужное |
| Не знаете, в каком режиме | `Esc` дважды, смотрите строку состояния внизу |

## 11. Vim vs nano (кратко)

На многих VPS есть **nano** (`Ctrl+O` сохранить, `Ctrl+X` выйти). Vim мощнее для массовых правок, макросов и больших логов; nano проще для одной строки в конфиге.

```bash
nano /etc/hosts              # простой редактор в терминале
update-alternatives --display editor   # какой editor по умолчанию (Debian/Ubuntu)
sudo update-alternatives --config editor   # выбрать vim/nano
```

## 12. Мини‑чек‑лист «правлю конфиг на сервере»

1. `sudoedit /path/to/conf` — не `vim` от root без нужды.
2. `:set nu` — сверить номер строки из ошибки (`nginx: line 42`).
3. Правки → `:wq`.
4. Проверка: `nginx -t`, `systemctl reload nginx` (не restart без причины).
5. Откат: бэкап копии или `git` / snapshot провайдера.
