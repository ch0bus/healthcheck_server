Шпаргалка по мониторингу в реальном времени
==========================================

## 1. htop — расширенный top

```bash
htop
```

Основные фишки:

- Цветной интерфейс, удобнее, чем `top`.
- F6 — выбор сортировки (по CPU, памяти и т.д.).
- F3 — поиск процесса.
- F9 — убить процесс.

Полезно: смотреть, кто именно грузит CPU/память прямо сейчас.

---

## 2. iotop — дисковая активность

```bash
sudo iotop
```

Показывает, какие процессы создают нагрузку на диск (чтение/запись).

Ключи:

```bash
sudo iotop -o   # показывать только процессы с ненулевой I/O активностью
```

---

## 3. iftop — сетевой трафик по соединениям

```bash
sudo iftop -i eth0
```

Показывает, кто с кем общается и сколько трафика идёт в реальном времени.

Клавиши:

- `t` — переключение отображения (текущая, средняя нагрузка и т.п.).
- `S` / `D` — сортировка по исходящему/входящему трафику.

Интерфейс (`eth0`, `ens3` и т.д.) нужно подобрать под вашу систему.

---

## 4. nload — общий входящий/исходящий трафик

```bash
sudo nload
sudo nload eth0
```

Показывает графики входящего/исходящего трафика по интерфейсам.
Подходит для быстрой оценки: "нас сейчас кто‑то заливает?".

---

## 5. Дополнительные полезные утилиты

### iostat (из пакета sysstat)

```bash
iostat -x 1 10
```

Показывает загрузку дисков (util, await и др.). Полезно при подозрении на дисковое узкое место.

### vmstat

```bash
vmstat 1 10
```

Общая картина по CPU, памяти, свопу, ожиданию I/O.

### dstat / atop / glances

Более продвинутые мониторы, объединяющие несколько метрик в одном интерфейсе.

---

## 6. Минимальный набор для "смотреть прямо сейчас"

- CPU/память/процессы: `htop`
- Диск: `iotop`, `iostat`
- Сеть (соединения): `iftop`
- Сеть (общий трафик): `nload`
